# Task 2: To-Do List Application (GUI)

A premium, responsive, and modern To-Do List application built using Python's standard `tkinter` library. It features a sleek dark mode theme, scrollable layout for large lists, CRUD operations, and persistent JSON-based storage.

## Features

- **Add Tasks**: Quickly add tasks by typing and pressing Enter or clicking "+ Add Task".
- **Complete Tasks**: Mark tasks as completed using checkboxes; the task text is visually struck-through and faded.
- **Delete Tasks**: Remove individual tasks with a stylized delete (`✕`) button.
- **Task Persistence**: Tasks are saved automatically in real-time to a `tasks.json` database.
- **Task Summary**: Displays live statistics at the bottom showing how many tasks are completed.
- **Modern UI**: Styled with a dark/cyan color scheme, custom hover highlights, and Segoe UI typography.

## Files

- `todo_app.py`: The Python application source code.
- `tasks.json`: Auto-generated database storing the task data in structured JSON format.

## How to Run

Run the application directly using Python:
```bash
python todo_app.py
```

## Dependencies
- Standard Python 3.x installation (no external pip packages required).
